## 📋 What to Do at Each Stage (Keep It Simple)

### Stage 1: NEW → WORKING
**One Goal: Get them to upload docs TODAY**

```
Call Script (30 seconds):
"Hi [Name], just saw your application for $[Amount]. 
Good news - I can get you funded this week. 
Takes 5 minutes to upload 3 bank statements. 
Can you do that while I'm on the phone?"
```

**If YES**: Send link, stay on phone, move to WORKING  
**If NO**: "What's stopping you?" → Handle objection → Set specific time  
**If NO ANSWER**: Leave VM → Send text → Call again in 2 hours

### Stage 2: WORKING → DECISION  
**One Goal: Get complete docs within 48 hours**

```
Day 1: Welcome call (you just did this)
Day 2: "Missing docs" text + call
Day 3: "Last chance" call → NURTURE if no response
```

**The Magic Question**: "What's the ONE thing preventing you from uploading right now?"

### Stage 3: DECISION → FUNDED
**One Goal: Close within 2 hours of offer**

```
Offer Call Script (45 seconds):
"[Name], great news! You're approved for $[Amount].
The rate is [X]% with [Term] payments of $[Amount].
This expires at midnight tonight.
Do you want me to send the contract now?"
```

**THREE OUTCOMES ONLY**:
1. **YES** → Send contract, stay on until signed
2. **MAYBE** → "What questions do you have?" → Answer → Ask for YES again
3. **NO** → "I understand. What would make this work for you?" → Note it → NURTURE
